# Smart Expense Tracker - Web Version

A responsive web version of the Smart Expense Tracker project.

## Features
- Add daily expenses
- Select expense category
- Calculate total spending
- View expense count
- Filter by category
- Delete expenses
- Save data in browser localStorage
- Responsive design

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
Open `index.html` in any modern web browser.

No server or installation is required.
